# NOT TODAY

一本十八天的互动小说。

你在一间下雨的出租屋里开机、开箱、干活、看一眼桌上的旧东西、关机。新世界每天比前一天更温柔，也更读不懂；箱子里的旧东西每天比前一天更清楚。第十八天，箱底是一张你寄给你自己的邮单。

**在线阅读：** https://haodaz.github.io/nottoday/

## 怎么玩

- 打开 `index.html`，填一个名字，从第 1 天开始。每一节末尾选一个做法，有的选择要等桌上有了某件东西才会出现。
- 左页是现场：这间屋子、桌上有什么、夜里缝里伸出来的东西。按住可以拖，点桌子可以凑近。
- 右页是书。
- 进度存在你自己的浏览器里，没有账号。换设备或清了浏览器数据会从第 1 天重来；要带走进度，用左下角的"存档码"。
- 请用 Safari 或 Chrome 打开，不要用微信内置浏览器。

单个 HTML 文件约 50MB，素材全部内嵌，第一次打开请耐心。

## 这个仓库里有什么

| 文件 | 说明 |
|---|---|
| `index.html` | 互动读本，自包含 |
| `bible.html` | 设定集：世界、物件、十八天、克总、结局 |
| `concept/` | 阶段 3–5 的崩坏与三个结局的概念图 |
| `tools/assemble-gamebook.mjs` | 把分节 JSON 装订成读本的脚本 |
| `tools/gen-image.mjs` | 出图脚本（阿里云百炼 qwen-image） |

游戏本体将在 2026 年 10 月 30 日之后另开仓库，用 Kiro 实现；那边的文本和素材都来自这里。
